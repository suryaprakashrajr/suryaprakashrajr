A Redis-inspired database developed from scratch using Java 21 to understand database internals, networking and concurrent programming.

**Key Highlights**
- Built a TCP socket-based server.
- Implemented multiple simultaneous client connections.
- Used ConcurrentHashMap for thread-safe storage.

- Implemented automated testing using JUnit 5.

**Technologies:** Java 21, Maven, TCP Sockets, ConcurrentHashMap, JUnit 5.

### 2. SignConnect – Accessible Video Communication Platform

Designed and developed a standalone web application focused on improving digital communication accessibility for Deaf, Hard-of-Hearing and non-verbal individuals.

**Key Highlights**
- Real-time peer-to-peer video communication using WebRTC.
- Live speech-to-text captioning.
- Static Indian Sign Language gesture recognition.
- Hand landmark detection using MediaPipe.

- Responsive web interface.

**Technologies:** HTML5, CSS3, JavaScript, WebRTC, PeerJS, Web Speech API, MediaPipe Hands.

**Project Status:** Completed.
